# Open Source Assessments

This directory contains tools and templates for assessing your organization's open source maturity and establishing program goals.

## Contents

- [Assessment Guide](assessment-guide.md) - Step-by-step instructions for completing the open source self-assessment
- [Open Source Self-Assessment](open-source-assessment.md) - Template for documenting your current state and goals

## Purpose

The assessment process helps your organization:

1. Understand your current level of open source maturity across key dimensions
2. Establish realistic goals for improvement
3. Develop a concrete action plan to achieve those goals
4. Track progress over time

## How to Use

1. Start by reading the [Assessment Guide](assessment-guide.md)
2. Complete the self-assessment using the [online tool](https://githubtraining.github.io/oss-assessment/)
3. Document your results and goals in the [Open Source Self-Assessment](open-source-assessment.md)
4. Review and update the assessment regularly as your program evolves

## Next Steps

After completing your assessment:

1. Share the results with key stakeholders
2. Develop policies and processes based on your action plan
3. Implement the necessary changes to reach your goals
4. Reassess periodically to track progress
